Requirements

What a trial must report, and how "enough" is decided: requirement sets in src/trialwatch/checks/requirement_sets/, read by the evidence check (ADR-004). The check's code and prompt name no registry or regulation; a set does. One current text per set while we build v1; every run stores the set it read, with its sha256.
